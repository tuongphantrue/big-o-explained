# Big O Field Guide

A single-page, single-file site that explains Big O notation and time complexity using everyday examples (phone books, classroom handshakes, doubling coins) instead of jargon — plus a live chart you can drag to compare how six common complexity classes grow.

**[View it live →](https://tuongphantrue.github.io/big-o-explained/)**

## What's inside

- **Interactive chart** — a slider for input size `n` that shows, in real time, how many steps `O(1)`, `O(log n)`, `O(n)`, `O(n log n)`, `O(n²)`, and `O(2ⁿ)` each take.
- **Plain-language explanations** — each complexity class paired with a simple real-world story.
- **Reference table** — complexity of common operations (arrays, linked lists, hash maps, trees, heaps, binary search).

No frameworks, no build step, no dependencies other than Google Fonts. Everything lives in `index.html`.

## Running it locally

Just open `index.html` in a browser — no server or install required.

## Deploying with GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Source**, choose the branch you pushed to (usually `main`) and the `/ (root)` folder.
4. Save. Your page will be live at:
   ```
   https://<your-username>.github.io/<repo-name>/
   ```
